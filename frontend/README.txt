HRL SERVICE PROVIDER - FYP STATIC WEBSITE

Pages:
- index.html       Home
- services.html    All services
- booking.html     Booking form
- contact.html     Contact form
- login.html       Login demo
- services/       8 individual service pages

Services:
Plumbing, Electrician, Cleaning, Painter, Car Repair, Care Services, Tutor, IT Support.

Run:
1. Extract/open the folder in VS Code.
2. Open index.html in a browser, or use VS Code Live Server.
3. Internet is needed for Font Awesome icons and Unsplash images.
4. Forms are front-end demo forms. Booking uses localStorage only; real login/database requires a backend such as Django/PHP/Node.

Theme:
Blue/white responsive design shared across every page.


Updated features:
- Services dropdown menu in the header on every page, listing all 8 service categories.
- Separate hero/banner image for every service detail page and major top-level page.
- Service dropdown works responsively on mobile.
